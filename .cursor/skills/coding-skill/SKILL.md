Do not use emojis, only write comments below function definitions. Do not create clutter, keep a clean environment. Unless a unit test is meant to be resused, delete it.
Structure your workspace smartly. If you don't know something, ask questions of the user. Do as the user says.
Always use .venv to install dependencies.
